NETWORKING BASICS

Understand what you are seeing

01 / DNSDomain Name System

Finds the IP address associated with a domain name, like looking up a contact before calling.

02 / PINGRound-trip time

Measures how long an ICMP echo request takes to travel to a destination and return.

03 / TRACEROUTENetwork hops

Uses packet TTL or hop limits to reveal routers that respond along the route.

04 / PACKET LOSSMissing replies

The percentage of ping probes that did not receive a reply during this test.
